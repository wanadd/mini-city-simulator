# Mini City Simulator

Русскоязычная браузерная игра о строительстве и экономике островного города. Для карты нужен браузер с WebGL 2.

## Запуск и проверка

Рекомендуется Node.js 20 или новее.

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Для установленного Chrome можно задать `CITY_BROWSER_CHANNEL=chrome`. По умолчанию Playwright проверяет производственную сборку на локальном сервере. Переменная `CITY_URL` с завершающим слешем позволяет проверить опубликованную сборку теми же сценариями.

Каталог `dist/` можно целиком отдать любому HTTPS-хостингу статических файлов. Пути к ассетам относительные. Секреты, база данных и серверный API игре не требуются.

## Правила

Один ход продвигает часы на два игровых часа. Доходы и содержание начисляются раз за ход. Повышение налогов увеличивает доход и снижает удовлетворённость. Рабочие места и доступное жильё ограничивают рост города. Действующие заводы ухудшают экологию, а работающие парки улучшают её и повышают довольство.

Дороги образуют отдельные сети. Чтобы сеть заработала, хотя бы одна дорога в ней должна доходить до границы карты. Здания подключаются к соседней дороге по горизонтали или вертикали. Если у здания несколько независимых сетей по соседству, выбирается сеть с ближайшим по порядку обхода карты выходом на берег. Электростанция питает только свою сеть. При дефиците мощность выделяется жилью, затем торговле и заводам. Парки и электростанции требуют доступа к дорогам.

Сохранение хранится в браузере. Ссылка содержит снимок города в URL-фрагменте и открывает отдельную копию на паузе. При сохранении открытой копии браузер запоминает её как свой город и убирает снимок из текущего адреса. Ссылка включает карту, игровой ход, население, бюджет, налог и историю последних 48 ходов. Выбранный инструмент, камера и очередь отмены принадлежат текущему сеансу.

## Устройство проекта

- `src/simulation.ts` — чистые переходы симуляции, инфраструктура, строительство и отмена.
- `src/persistence.ts` — формат версии 1, валидация сохранений и переносимый снимок города.
- `src/scene.ts`, `src/models.ts` — Three.js, камера, пакетная отрисовка геометрии, процедурные модели и анимация.
- `src/App.tsx`, `src/Chart.tsx`, `src/style.css` — интерфейс и интерактивные графики.
- `tests/` — тесты модели и браузерные сценарии для десктопа и мобильного разрешения.

Исходники публикуются из ветки `main`. GitHub Pages обслуживает сборку из корня отдельной ветки `gh-pages`.
